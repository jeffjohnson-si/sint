Features
A full platform, not just a feed.

Four account types, interest-aware ranking, subscription gating, verified badges, direct messaging, and an offline payment flow — all production-ready.

👥
Four Account Types
Users, businesses, companies and freelancers — each with the right permissions. Only publishers see the Create Post tab; the rest get a clean browse-only experience.
📰
Interest-Aware Feed
New users pick categories at onboarding. Posts in those categories rank as if up to 2 days newer — without filtering out everything else. Skipping the form still shows all business posts.
💳
Subscription & Billing
Monthly (SBD 150) and yearly (SBD 1,500) plans with a 14-day free trial, verified badge on yearly plans, and a boost that pushes posts higher in the feed. Stripe-powered with an offline payment fallback for Solomon Islands.
🔍
Smart Search & Suggestions
Keyword search maps everyday terms to categories ("food" → Food & Drinks). Suggestions rank by the viewer's search, follow, like, save and comment history. Paid publishers always appear first.
💬
Direct Messaging
Real conversations between any account types. Messages carry text, images and video. Notification badges refresh every 10 seconds via polling — no websockets required.
🛡️
Security & Rate Limiting
JWT access + refresh tokens, password reset flow, per-route rate limiting, Stripe webhook signature verification, and MongoDB unique indexes preventing payment replay attacks.
Tech Stack
Built to last, built to scale.

Flutter on the front-end, Node.js Express 5 on the back-end, MongoDB for persistence — with indexes, lean queries and disk-backed sorting ready for thousands of users.

🦋
Flutter
Cross-platform mobile & web app using Provider for state management
🟢
Node.js Express 5

🍃
MongoDB + Mongoose 9
Compound indexes, lean queries, allowDiskUse on large sorts, autoIndex in dev only
🔑
JWT Auth
Access + refresh token pair, stored in Flutter SecureStorage, auto-refresh on expiry
📷

⚡
Interest Ranking
MongoDB aggregation pipeline with boost windows and category interest scores
